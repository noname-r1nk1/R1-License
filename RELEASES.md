# R1 Licensed Releases

This file records addon releases published under the **R1 Non-Monetized Modpack License**.

For each release, record the exact archive name and its **SHA-256** hash. The hash identifies the exact archive to which the listed license version was distributed.

## Release registry

_No addon releases have been registered here yet._

### Template

```text
Addon: [Addon name]
Version: [Addon version]
Release date: [YYYY-MM-DD]
Archive: [exact archive filename]
SHA-256: [64-character SHA-256 hash]
License: R1 Non-Monetized Modpack License v1.0
Official release: [ModDB or other official release URL]
```

## Notes

- A SHA-256 hash identifies file contents; it is not a digital signature.
- The copy of `R1_LICENSE.txt` included in a release archive remains the license copy distributed with that release.
- Do not rewrite old license versions. Publish a new version if the license terms change.
