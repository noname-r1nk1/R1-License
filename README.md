## What this license is for

The license permits R1 addons to be included and adapted for **non-monetized modpacks**, while requiring original attribution and preserving the license.

In short:

- modpack inclusion is allowed;
- compatibility/configuration fixes and integration changes are allowed;
- rebranding or publishing the addon as somebody else's standalone addon is not allowed;
- monetization of the addon, modpack, launcher, installer, download, or distribution is not allowed;
- monetized YouTube/Twitch videos, streams, reviews, and guides are allowed.

The complete license text controls. This summary does not replace it.

## Using the license with an addon

Each covered addon release should include a local copy named:

`R1_LICENSE.txt`

The release may also link back to this repository as the public canonical copy.
